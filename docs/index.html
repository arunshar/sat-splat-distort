Abstract

Standard 3D Gaussian Splatting assumes a pinhole camera, so it breaks on the cameras that matter for Earth observation. Sat-Splat-Distort derives the exact projection Jacobian in closed form for four non-pinhole camera models and validates each numerically against torch.autograd, then adds a learned distortion-prior grid for residual lens noise.

Honest scope. The genuine, tested contribution is the four closed-form camera Jacobians (each validated against autograd) and the learned distortion-prior grid module. The full GPU 3DGS fit uses a forked CUDA rasterizer that is loaded lazily and stubbed for CPU smoke; the README PSNR numbers (e.g. 24.2 on DFC2019) are leaderboard targets, not reproduced.

Validated output

20/20 tests pass (run live). Reproduced number: the analytic camera Jacobians match torch.autograd to ~1e-5 relative error (equirectangular ~1.8e-6, fisheye ~1.0e-5), the closed-form correctness claim is reproduced, not asserted. Full output in docs/EVIDENCE.md.
